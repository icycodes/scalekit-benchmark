# AgentKit: List Scoped Tools for a Connected Account (Python) ## Background Scalekit's AgentKit exposes pre-built, LLM-ready tools for every connector in its catalog. Before an agent can call any of those tools on behalf of a user, your app must enumerate the tool definitions that the user is currently authorized to invoke. The `list_scoped_tools` API returns the JSON-Schema tool definitions for a given `identifier` and an optional connection-name filter. For this task, the Scalekit workspace already has a `github-test` connection set up and a connected account for the identifier `zealt-user01` in `ACTIVE` state. Your job is to write a small Python script that lists the scoped tools available for that user on the `github-test` connection and saves the discovered tool names as JSON. A common friction point with this API is that the default page size hides tools for large connectors. Your script must explicitly request `page_size=100` so that all GitHub tools are returned. ## Requirements * Initialize a `ScalekitClient` using the Scalekit credentials from the environment. * Call `list_scoped_tools` for identifier `zealt-user01`, filtering on the connection name `github-test`, with `page_size=100`. * Extract the tool `name` for every returned scoped tool. * Write the extracted tool names as a JSON array of strings to `/home/user/myproject/tools.json`. * Write a short log line to `/home/user/myproject/output.log` confirming success and the number of tools discovered. ## Implementation Hints * Install and use the official `scalekit-sdk-python` package. * Read `SCALEKIT_ENV_URL`, `SCALEKIT_CLIENT_ID`, and `SCALEKIT_CLIENT_SECRET` from environment variables. * The `github-test` connection name is workspace-fixed; hard-code it in the script (do not introduce a new env var for it). * The Python SDK returns a protobuf-like response; converting each scoped tool to a dict (for example via `google.protobuf.json_format.MessageToDict`) makes it easy to read `definition.name`. * Be sure to pass `page_size=100` so that all tools for the GitHub connector are included. ## Acceptance Criteria * Project path: /home/user/myproject * Ensure the script is executed and the artifacts exist. * Log file: /home/user/myproject/output.log * The log file must contain a line in the format: `Tools discovered: <count>` where `<count>` is the integer number of tools written to `tools.json`. * The output file `/home/user/myproject/tools.json` must exist and contain a JSON array of strings. * Every entry in the JSON array must be a tool name (string) returned by Scalekit's `list_scoped_tools` for identifier `zealt-user01` on connection `github-test`. * The array must include at least one GitHub-related tool name (i.e., a tool name beginning with `github_`). * The array must contain at least 20 tool names (large connectors expose far more than the default page size).
