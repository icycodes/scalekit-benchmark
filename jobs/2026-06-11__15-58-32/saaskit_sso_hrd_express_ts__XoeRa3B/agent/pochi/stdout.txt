| Route | Behavior |
|---|---|

**Key implementation details:**
- Uses `@scalekit-sdk/node` SDK's `ScalekitClient` for authorization URL generation and code exchange
- JWT payload decoded via base64url decode (no crypto verification needed per requirements)
- Logout URL manually constructed as `{SCALEKIT_ENV_URL}/oidc/logout?id_token_hint=...&post_logout_redirect_uri=...` since the SDK doesn't expose a `getLogoutUrl` method
- `cookie-parser` middleware for reading cookies on subsequent requests
- All cookies set with `httpOnly: true` and `path: '/'`
- `refreshToken` cookie set to empty string since the SDK's `AuthenticationResponse` doesn't include a refresh token field
