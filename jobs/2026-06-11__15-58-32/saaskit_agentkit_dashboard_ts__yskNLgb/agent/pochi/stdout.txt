# Scalekit SaaSKit + AgentKit: Build an Express.js Web App that Shows the Signed-in User's GitHub Repos ## Background Scalekit ships two complementary products under a single SDK: **SaaSKit** (hosted login, OIDC, sessions, organizations, RBAC) and **AgentKit** (per-user connected accounts to 100+ SaaS apps such as GitHub and Slack). A very common real-world pattern is to combine them: a user signs into your product via SaaSKit, and then your authenticated routes call AgentKit tools on the user's behalf so the agent can read/write the user's third-party data without you ever touching OAuth tokens. In this task you will build a small Express.js web application that wires **both** kits end-to-end so a real human user (driven by a browser agent during verification) can: 1. Open the landing page and click "Sign in". 2. Complete Scalekit's hosted login flow using the preconfigured test user + static OTP. 3. Land on a protected dashboard that (a) shows their signed-in email and (b) shows a list of GitHub repositories belonging to the AgentKit-connected GitHub account, fetched live via Scalekit AgentKit on behalf of the dashboard user. 4. Click a sign-out control and land on a public goodbye page.
