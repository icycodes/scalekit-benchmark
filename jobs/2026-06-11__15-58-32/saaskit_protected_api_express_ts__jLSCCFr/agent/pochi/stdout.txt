## Key design decisions
- **`requireAuth(mode)` middleware factory** — reused for both `/dashboard` (redirects to `/login` on failure) and `/api/me` (returns 401 JSON on failure). Any error thrown by `validateAccessToken` is caught and treated as invalid.
- **`decodeIdToken()`** — base64url-decodes the JWT payload (no crypto verification needed; `validateAccessToken` covers that) to extract `email` and `sub` claims.
- **`getLogoutUrl` called before `clearCookie`** — avoids losing the `idToken` needed as `id_token_hint`.
- **Cookies** set with `{ httpOnly: true, sameSite: 'lax' }` for security; same options passed to `clearCookie` so the path matches.
