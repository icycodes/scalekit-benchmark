## Implementation Details

### Authentication Middleware (`authMiddleware`)
The middleware performs the following steps:

1. **Extracts Bearer token** from the `Authorization` header
2. **Validates token** using `scalekit.validateToken(token, { requiredScopes: ['todo:read'] })`
3. **Scope validation**: Checks if the token has the `todo:read` scope
4. **Response handling**:
   - Returns `401 Unauthorized` if token is missing or invalid
   - Returns `403 Forbidden` if token is valid but lacks required scope
   - Calls `next()` if validation succeeds

### Endpoints
- **GET /health**: Public health check endpoint (no authentication)
- **GET /todos**: Protected endpoint requiring Bearer token with `todo:read` scope

### Configuration
The Scalekit client is configured via environment variables:
- `SCALEKIT_ISSUER_URL`: Your Scalekit issuer URL (defaults to `https://auth.scalekit.dev`)
- `SCALEKIT_CLIENT_ID`: Your Scalekit client ID
- `SCALEKIT_CLIENT_SECRET`: Your Scalekit client secret
