### Endpoints

**`GET /.well-known/oauth-protected-resource`** — Public discovery endpoint (no auth required).  
Returns the OAuth 2.0 protected resource metadata:
```json
{
  "resource": "https://mcp.example.com",
  "authorization_servers": ["https://tabbyml.scalekit.dev/resources/res_123"],
  "bearer_methods_supported": ["header"],
  "scopes_supported": ["todo:read", "todo:write"]
}
```

**`POST /tools/execute`** — Protected endpoint that requires a valid Bearer token **and** the `todo:write` scope. Returns `{"status": "success"}` when authorized.

### Middleware

An HTTP middleware intercepts every request (except the discovery endpoint) and:
1. Extracts the `Bearer` token from the `Authorization` header — returns `401` if missing/malformed.
2. Calls `scalekit_client.validate_token(token)` — returns `401` if the token is invalid or expired.
3. Attaches the decoded claims to `request.state.token_claims` for downstream use.

### Scope Enforcement

`/tools/execute` reads `scp`/`scope` from the validated claims and returns `403` if `todo:write` is not present.
