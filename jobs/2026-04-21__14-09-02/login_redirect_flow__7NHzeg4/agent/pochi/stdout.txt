### What was implemented

**`server.js`** sets up:

1. **`express-session`** middleware — stores the CSRF `state` token per user session.
2. **`ScalekitClient`** — initialized from three environment variables:
   - `SCALEKIT_ENV_URL`
   - `SCALEKIT_CLIENT_ID`
   - `SCALEKIT_CLIENT_SECRET`
3. **`GET /login`** route:
   - Generates a 16-byte cryptographically random `state` string via `crypto.randomBytes`.
   - Stores it in `req.session.oauthState` for later CSRF verification on the callback.
   - Calls `scalekit.getAuthorizationUrl('http://localhost:3001/callback', { state, organizationId: organization_id })` using the `organization_id` query parameter.
   - Redirects the user to the returned Scalekit authorization URL.
4. Listens on **port 3001**.

### How to run

```bash
cd /home/user/scalekit-app

node server.js
```

The user will be redirected to Scalekit's authorization server to complete SSO login.
