## Implementation Details (`server.js`)

**Dependencies installed:** `express`, `body-parser`, `@scalekit-sdk/node`

**Key design decisions based on SDK inspection:**
- `bodyParser.raw({ type: 'application/json' })` is applied only to the `/webhook` route, preserving the exact raw bytes needed for HMAC verification.
- `ScalekitClient` is initialized once at startup. The `verifyWebhookPayload(secret, headers, payload)` method is purely local HMAC computation — no network calls.
- The SDK's `verifyWebhookPayload` reads `webhook-signature` from the headers map. The incoming `X-Scalekit-Signature` header value is merged into the headers map under the `webhook-signature` key so the SDK can find it.
- On success: the event `type` field is extracted from the parsed JSON body and appended to `events.log` with an ISO timestamp, then a `200` is returned.
- On failure (missing headers, invalid/tampered signature, expired timestamp): a `401` is returned with an error message.
