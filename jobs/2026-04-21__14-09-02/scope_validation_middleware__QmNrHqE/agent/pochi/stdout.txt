## What was implemented (`server.js`)

### Scalekit Client Initialization
```js
const scalekit = new Scalekit(
  process.env.SCALEKIT_ENV_URL,
  process.env.SCALEKIT_CLIENT_ID,
  process.env.SCALEKIT_CLIENT_SECRET
);
```
Credentials are read from environment variables.

### `authMiddleware`
| Step | Behavior |
|---|---|
| No/malformed `Authorization` header | Returns `401 Unauthorized` |
| Token fails `validateToken()` (expired/invalid) | Returns `401 Unauthorized` |
| Token valid but missing `todo:read` scope | Returns `403 Forbidden` |
| Token valid with required scope | Calls `next()` and attaches claims to `req.user` |

The middleware calls:
```js
await scalekit.validateToken(token, { requiredScopes: ['todo:read'] });
```

### Protected Route
```
GET /todos  →  protected by authMiddleware  →  returns list of todos
```
