## How it works

1. **Scalekit client** is initialized using three environment variables:
   - `SCALEKIT_ENVIRONMENT_URL`
   - `SCALEKIT_CLIENT_ID`
   - `SCALEKIT_CLIENT_SECRET`

2. **`GET /callback`** route:
   - Extracts `code` and `state` from query parameters
   - Returns `400` if `code` is missing
   - Calls `scalekit.authenticateWithCode(code, 'http://localhost:3001/callback')` to exchange the code for tokens
   - Decodes the `idToken` using `jwt.decode()` (no signature verification — claims extraction only)
   - Returns `{ email, name }` from the decoded token as JSON
   - Returns `500` with error details on any failure

## Running the server

```bash
# Set required environment variables
export SCALEKIT_ENVIRONMENT_URL=https://your-env.scalekit.com
export SCALEKIT_CLIENT_ID=your_client_id
export SCALEKIT_CLIENT_SECRET=your_client_secret

# Start the server
cd /home/user/scalekit-callback
node server.js
# → Scalekit callback server running on http://localhost:3001
```
