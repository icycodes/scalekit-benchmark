# Scalekit SaaSKit + AgentKit: Build an Express.js Web App that Shows the Signed-in User's GitHub Repos ## Background Scalekit ships two complementary products under a single SDK: **SaaSKit** (hosted login, OIDC, sessions, organizations, RBAC) and **AgentKit** (per-user connected accounts to 100+ SaaS apps such as GitHub and Slack). A very common real-world pattern is to combine them: a user signs into your product via SaaSKit, and then your authenticated routes call AgentKit tools on the user's behalf so the agent can read/write the user's third-party data without you ever touching OAuth tokens. In this task you will build a small Express.js web application that wires **both** kits end-to-end so a real human user (driven by a browser agent during verification) can: 1. Open the landing page and click "Sign in". 2. Complete Scalekit's hosted login flow using the preconfigured test user + static OTP. 3. Land on a protected dashboard that (a) shows their signed-in email and (b) shows a list of GitHub repositories belonging to the AgentKit-connected GitHub account, fetched live via Scalekit AgentKit on behalf of the dashboard user. 4. Click a sign-out control and land on a public goodbye page. The Scalekit environment has been preconfigured with the following fixtures (use them verbatim, do **NOT** invent new credentials, do **NOT** introduce any environment variables that are not provided): * SaaSKit: * Allowed callback URL: `http://localhost:3000/callback` * Initiate-login URL: `http://localhost:3000/login` * Post-logout URL: `http://localhost:3000/goodbye` * Test user email: `zealt-user01+sktest@test.com` * Static OTP for the test user: `424242` * AgentKit: * GitHub connection name: `github-test` * Slack connection name: `slack-test` * Both connections have an `ACTIVE` connected account whose identifier is `zealt-user01` Scalekit SDK credentials are provided through the environment variables `SCALEKIT_ENV_URL`, `SCALEKIT_CLIENT_ID`, and `SCALEKIT_CLIENT_SECRET`. No other Scalekit environment variables exist. ## Requirements * Build an Express.js application (Node.js) using the official `@scalekit-sdk/node` SDK. For each rendered repository, the page must include the repository's `full_name` (in the form `owner/name`) or its `html_url`. A visible "Sign out" / "Logout" link or button targeting `GET /logout` must also be present. * `GET /logout` — produce the Scalekit logout URL via `scalekit.getLogoutUrl(idToken, 'http://localhost:3000/goodbye')` BEFORE clearing cookies, then clear the `accessToken`, `refreshToken`, and `idToken` cookies and HTTP-redirect the browser to the logout URL. * `GET /goodbye` — a public page that visibly confirms the user has signed out (must contain a clearly visible "signed out" / "goodbye" / "logged out" message). ## Implementation Hints * Install the SDK with `npm install @scalekit-sdk/node express cookie-parser` (add `typescript`/`tsx` if you want to write TypeScript). * Initialize the SDK with `new ScalekitClient(process.env.SCALEKIT_ENV_URL!, process.env.SCALEKIT_CLIENT_ID!, process.env.SCALEKIT_CLIENT_SECRET!)`.
